# Research Thesis

## Primary question
> Can an Interaction Fingerprint — combining explicit behavior, behavioral patterns, attention and non-verbal interaction signals — reveal actionable product insights that conventional interaction analytics miss?

## Secondary question
> Can an agent use those signals to adapt a generative interface in a way that measurably improves the user's experience?

## Hypotheses
- **H1:** Interaction Fingerprints contain useful information that conventional click/scroll analytics do not capture.
- **H2:** Fingerprint patterns can identify possible decision friction before explicit abandonment.
- **H3:** An agent can use the fingerprint to choose a useful interface intervention.
- **H4:** A perceptive/adaptive interface can improve decision confidence, task success, or efficiency versus a non-perceptive baseline.

## Falsification
The project must be willing to conclude that gaze adds little value, facial signals are too noisy, behavioral signals are sufficient, adaptation is distracting, or users do not want this sensing.

A negative result is valid research.

## Novelty direction
Do not claim eye tracking, facial tracking, adaptive retail, biometric UX research, or generative UI is new.

The exploration is specifically about using a combination of observable interaction signals as an active input layer for agentic and generative interfaces.
